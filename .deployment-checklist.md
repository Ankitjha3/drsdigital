# Pre-Deployment Checklist

Use this checklist before deploying to production.

## Database Setup
- [ ] Switched from SQLite to PostgreSQL
- [ ] Updated `prisma/schema.prisma` provider to "postgresql"
- [ ] Created production database (Vercel Postgres, Supabase, Neon, etc.)
- [ ] Updated `DATABASE_URL` environment variable
- [ ] Ran `npx prisma migrate dev --name init`
- [ ] Tested database connection locally

## Environment Variables
- [ ] Created `.env` file from `.env.example`
- [ ] Generated `NEXTAUTH_SECRET` using `openssl rand -base64 32`
- [ ] Set `NEXTAUTH_URL` to production URL
- [ ] Added Razorpay credentials (`RAZORPAY_KEY_ID`, `RAZORPAY_KEY_SECRET`)
- [ ] Added UploadThing credentials (`UPLOADTHING_SECRET`, `UPLOADTHING_APP_ID`)
- [ ] Verified all environment variables are set

## Code Quality
- [ ] Run `npm run lint` - no errors
- [ ] Run `npm run build` - builds successfully
- [ ] Tested locally with `npm run dev`
- [ ] All features work as expected
- [ ] No console errors in browser

## Git Repository
- [ ] Code is committed to Git
- [ ] Pushed to GitHub/GitLab/Bitbucket
- [ ] `.env` file is in `.gitignore` (not committed)
- [ ] Database files are in `.gitignore`

## External Services
- [ ] Razorpay account is set up
- [ ] Razorpay is in test mode (for initial deployment)
- [ ] UploadThing account is set up
- [ ] UploadThing app is created

## Deployment Platform
- [ ] Created account on Vercel or Netlify
- [ ] Connected Git repository
- [ ] Added all environment variables in platform dashboard
- [ ] Configured build settings (auto-detected for Next.js)

## Post-Deployment
- [ ] Run database migrations on production
- [ ] Test user registration
- [ ] Test user login
- [ ] Test product browsing
- [ ] Test add to cart
- [ ] Test checkout flow (with test payment)
- [ ] Test file uploads
- [ ] Test admin panel access
- [ ] Verify all API routes work

## Production Readiness
- [ ] Switch Razorpay to live mode
- [ ] Update Razorpay webhook URL to production
- [ ] Add production domain to UploadThing allowed origins
- [ ] Set up custom domain (optional)
- [ ] Configure error monitoring (optional: Sentry)
- [ ] Set up analytics (optional: Google Analytics, Plausible)
- [ ] Create admin user account
- [ ] Add initial products

## Security
- [ ] All secrets are stored as environment variables
- [ ] No sensitive data in Git repository
- [ ] HTTPS is enabled (automatic on Vercel/Netlify)
- [ ] Database connection uses SSL
- [ ] Rate limiting considered for API routes (optional)

## Documentation
- [ ] Updated README.md with production URL
- [ ] Documented any custom setup steps
- [ ] Created admin user guide (if needed)
